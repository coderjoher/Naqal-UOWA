Callers of the API: the React dashboard (src/lib/api.ts fetch wrapper adding `Authorization: Bearer <token>` from localStorage, src/lib/live.ts Socket.IO client) and the Flutter apps via naql_core (ApiClient over package:http, SocketLiveFeed; the driver app's SyncQueue retries queued actions/GPS with client-generated ids). All send a JWT bearer token obtained from /auth/login, student sign-in or driver OTP verify.
