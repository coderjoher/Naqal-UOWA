Controllers (registered flat in app.module.ts) read the authenticated user with @CurrentUser() and delegate to services. Services hold the business rules (pure *-rules.ts files for state machines), use PrismaService.db (tenant-scoped) and often db.$transaction(async tx => ...) with the Tx type, read configuration through ConfigCache and heavy office views through the officeViews SWR cache, enqueue BullMQ jobs instead of doing slow work inline (NF-03), and emit realtime events via LiveHub. tenantUniversityId() (tiers.service.ts) reads the current tenant for writes.
