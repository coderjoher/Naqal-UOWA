Injectable services per feature folder. Pattern: validate business preconditions (ConflictException / ForbiddenException / NotFoundException / BadRequestException), run tenant-scoped Prisma work, often in a transaction, then side effects (officeViews.invalidate, ConfigCache.invalidate, LiveHub emits, NotificationsService, queue.add). Pure decision logic lives in unit-tested *-rules.ts / domain files (driver-rules, run-rules, taxi-rules, wave-rules, tier-rules, dispatch/domain).
