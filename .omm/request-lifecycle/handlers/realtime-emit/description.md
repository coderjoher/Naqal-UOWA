Services push events to sockets through LiveHub (live/live.hub.ts) rather than the gateway: bus (position + ETAs) to run and ops rooms, run / run:updated to run, ops and driver rooms, taxi:ride, taxi:gone, notification to user rooms. With the Redis adapter, an emit from any worker reaches sockets on every worker; e.g. a driver's POST /runs/:id/gps batch on worker A updates students connected to worker B.
