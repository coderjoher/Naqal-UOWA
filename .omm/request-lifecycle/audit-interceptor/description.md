Global APP_INTERCEPTOR (audit/audit.interceptor.ts). Passes through unless the request is POST/PUT/PATCH/DELETE by an office or super_admin user and the handler is not marked @AuditedByHandler. After the handler resolves successfully it writes an AuditEvent under runAsSystem: universityId (the user's, or for super admin the changed record's), actorId, action `METHOD /route/pattern`, entity (controller name without "Controller"), entityId from result.id, and the request body with password/token/secret keys redacted. Failed requests are not audited.
