Global ValidationPipe({ whitelist: true, forbidNonWhitelisted: true, transform: true }) from setup-app.ts. Body/query DTO classes (e.g. runs.controller.ts RunActionsDto, GpsBatchDto; *.dto.ts in tiers, waves, points, drivers, students, universities, auth) use class-validator and class-transformer decorators (@IsUUID, @IsLatitude, @ArrayMaxSize(2000), @ValidateNested + @Type ...), which also drive the Swagger schema via @ApiProperty. Unknown fields -> 400, payloads are transformed into class instances. Path ids are checked with ParseUUIDPipe in most controllers.
