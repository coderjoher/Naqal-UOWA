handleConnection reads the JWT from handshake.auth.token (or ?token= query), verifies it with JwtService.verifyAsync (no token cache here), loads the user under runAsSystem and rejects (emit `error` {message: 'Unauthorized'} + disconnect) if missing, not active or without universityId — which also excludes super_admin. Stores {id, role, universityId} in socket.data.user, joins user:{id}, plus ops:{universityId} for office and driver:{id} for drivers, then emits `ready`.
