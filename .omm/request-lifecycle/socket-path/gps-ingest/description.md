`gps {runId, points[] | lat/lng/at/speed/heading}` from driver sockets (other roles get {ok:false, error:'forbidden'}). Forwarded to LiveService.ingest(driverId, universityId, runId, points), which accepts points only from the run's own driver while it is under way, writes Redis last point + GEO set, computes ETAs, broadcasts via LiveHub, persists one RunPosition per minute plus near-stop proof points, and fires approach notifications. The REST alternative POST /runs/:id/gps (GpsBatchDto, up to 2000 buffered points) goes through the full HTTP pipeline and reaches the same ingest method. Note the socket payload is not class-validated.
