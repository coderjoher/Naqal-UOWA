`join {runId}`: validates the UUID shape (WsException otherwise) and, inside runAsTenant(user.universityId), allows office users for any run of their university, drivers only for runs they drive, and students only when they hold an assigned/done RideRequest on that run (NF-02). On success joins run:{runId} and replies {ok: true, bus: LiveService.last(...)} with the last position from Redis (NF-10). `leave` removes the socket from the run room.
