LiveHub holds the Socket.IO server attached by LiveGateway.afterInit and emits to rooms run:{id}, ops:{uid}, user:{id}, driver:{id}, taxi:{uid}. RedisIoAdapter (installed by setupApp when REDIS_URL is set) wires @socket.io/redis-adapter with ioredis pub/sub clients on key {QUEUE_PREFIX}:io, so an emit from any cluster worker or REST handler reaches sockets connected to any worker (NF-01). Only bus positions are broadcast, never student locations (NF-12).
