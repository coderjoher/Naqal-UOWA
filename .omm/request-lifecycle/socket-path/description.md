Realtime path that bypasses the HTTP pipeline (no middleware, guards, interceptor or ValidationPipe). Clients connect to namespace /live (path /api/socket.io behind nginx) with `auth: { token }`; the dashboard and apps force the websocket transport so no sticky sessions are needed across cluster workers. LiveGateway (live/live.gateway.ts) authenticates in handleConnection, assigns rooms, and handles `join`, `leave` and `gps` messages with manual checks; LiveHub + RedisIoAdapter fan out server events to every worker.
