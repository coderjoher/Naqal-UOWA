The API is multi-tenant: a request has no universityId until JwtAuthGuard sets it from the authenticated user, and the Prisma extension refuses to query tenant models without that context. Public routes (@Public: /auth/login, student sign-in/activation, driver OTP send/verify, /health, /files/:token, /metrics) skip JWT but still run inside the empty tenant store, so their services must use runAsSystem or runAsTenant explicitly. Background BullMQ jobs follow the same rule without any HTTP layer.
