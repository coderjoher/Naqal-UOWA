JwtAuthGuard: returns true for @Public handlers/classes. Otherwise parses `Authorization: Bearer <jwt>` (401 if missing), verifies it with JwtService (HS256 secret JWT_SECRET, payload {sub, role, uid}) through tokenCache, then loads {id, role, universityId, status} for sub under runAsSystem through userCache (AUTH_CACHE_MS, default 10 s). 401 if the user is missing, not active, or a non-super-admin without universityId. Sets req.user = {id, role, universityId} and writes userId, role and either global=true (super_admin) or universityId into the request's TenantStore.
