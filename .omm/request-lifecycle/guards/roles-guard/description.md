RolesGuard reads ROLES metadata set by @Roles('office', 'super_admin', ...) on the handler or controller; with none it allows any authenticated user, otherwise throws 403 ForbiddenException when req.user.role is not listed. Finer checks (e.g. a driver may only act on their own run, office only on its university) happen in services, mostly implicitly through the tenant filter plus explicit ownership queries.
