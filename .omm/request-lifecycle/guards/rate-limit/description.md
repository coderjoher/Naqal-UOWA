RateLimitGuard reads @RateLimit rules from the handler; without rules it passes. For each rule it builds key `rl:{name}:{ip}:{account}:{window}` (account = lower-cased body fields such as email/studentId/university or phone), runs MULTI INCR + EXPIRE(window+5) in Redis and throws TooManyRequestsException (429, body retryAfterS, Retry-After header) above limit x RATE_LIMIT_FACTOR. Rule sets: LOGIN_LIMITS (10 per account / 300 per IP per 10 min), OTP_SEND_LIMITS (5 per phone / 60 per IP per hour), OTP_VERIFY_LIMITS (10 per phone / 300 per IP per 10 min). Applied on /auth/login, student-auth endpoints and driver OTP endpoints.
