Three global guards from auth/auth.module.ts (APP_GUARD providers, run in registration order). RateLimitGuard throttles handlers decorated with @RateLimit (sign-in and OTP) using Redis counters. JwtAuthGuard skips @Public handlers, otherwise verifies the bearer JWT, checks the user is active and belongs to a university (unless super_admin), sets req.user and fills the TenantStore. RolesGuard enforces @Roles(...) metadata (any authenticated user when absent).
