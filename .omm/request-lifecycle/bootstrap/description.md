main.ts loads observability/instrument.ts first (OpenTelemetry auto-instrumentation and Sentry, both opt-in by env). With API_WORKERS > 1 the cluster primary forks workers that share port 3000, restarts crashed ones and serves aggregated Prometheus metrics on METRICS_PORT; each worker (or the single process) runs bootstrap(): NestFactory.create(AppModule) -> setupApp() [helmet (no CSP), global SentryExceptionFilter, global ValidationPipe, RedisIoAdapter] -> trust proxy, CORS (CORS_ORIGIN or reflect any origin), shutdown hooks, Swagger at /docs and /docs/openapi.json -> listen(PORT). AppModule registers MetricsMiddleware + TenantMiddleware for `*path` and the global AuditInterceptor; AuthModule registers the three APP_GUARDs.
