nginx inside the dashboard and Flutter web images serves the SPA and proxies `location /api/` to http://api:3000/ (prefix stripped), with HTTP/1.1 Upgrade/Connection headers for Socket.IO at /api/socket.io/, 1 h read timeout and X-Forwarded-For. In the https profile Caddy (infra/caddy/Caddyfile) terminates TLS in front of those containers. The API trusts TRUST_PROXY_HOPS (default 1) so req.ip is the real client IP used by rate limiting.
