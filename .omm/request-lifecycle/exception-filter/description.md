Global SentryExceptionFilter (observability/sentry.filter.ts, @Catch() everything) extends Nest's BaseExceptionFilter. When SENTRY_DSN is set it reports the exception to Sentry unless it is an HttpException below 500; then delegates to BaseExceptionFilter, so clients receive Nest's standard JSON `{statusCode, message, error}` (validation errors carry message arrays, 429 adds retryAfterS). Unknown errors such as TenantContextMissingError or Prisma errors become 500. MetricsMiddleware counts 5xx responses separately.
