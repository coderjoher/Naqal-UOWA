Runs for every route before Nest guards. helmet (from setupApp) sets security headers with contentSecurityPolicy off and cross-origin resource policy. MetricsMiddleware (observability/metrics.ts) starts a histogram timer and on `finish` records naql_http_request_duration_seconds by method/route pattern/status and counts 5xx in naql_http_errors_total. TenantMiddleware (tenancy/tenant.middleware.ts) calls tenantStorage.run({}, next) so every later step of the request — guards, interceptors, handlers and awaited Prisma calls — shares one mutable TenantStore.
