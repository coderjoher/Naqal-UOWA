PrismaService (prisma/prisma.service.ts) exposes `db = new PrismaClient().$extends(tenantExtension)`. The extension (tenancy/tenant-scope.ts) intercepts $allModels.$allOperations and calls scopeArgs(model, operation, args, currentTenant()): models outside TENANT_MODELS pass through; with no context or an empty store it throws TenantContextMissingError; in global context (super_admin, runAsSystem) args are unchanged; otherwise it ANDs universityId into where for find/count/aggregate/groupBy/update/delete, stamps universityId on create/createMany/upsert, and throws CrossTenantWriteError when data targets another university. Because Prisma queries are lazy, runAsSystem/runAsTenant await inside the AsyncLocalStorage context.
