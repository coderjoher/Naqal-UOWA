Push notifications via Firebase Cloud Messaging HTTP v1 (apps/api/src/notifications/push.ts). When FCM_SERVICE_ACCOUNT holds a service-account JSON, FcmPushSender signs a JWT (jose, RS256), exchanges it at https://oauth2.googleapis.com/token (cached until near expiry) and POSTs to fcm.googleapis.com/v1/projects/{id}/messages:send with android priority high. 400/404 responses delete the stale DeviceToken row. Without the variable, LogPushSender only logs. NotificationsService sends push after commit, alongside the Socket.IO event.
