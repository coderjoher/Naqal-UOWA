GitHub-hosted CI/CD (.github/workflows/). Six workflows: CI on every push to main and PR, phase-gate traceability, demo APK builds published to the rolling `demo-apk` GitHub Release, signed store releases on `v*` tags, a weekly k6 load test and nightly property tests. Uses ubuntu-latest (macos-15 for TestFlight), actions/checkout, pnpm/action-setup, setup-node, subosito/flutter-action (Flutter 3.47.6), setup-java (Temurin 17) and grafana/setup-k6-action.
