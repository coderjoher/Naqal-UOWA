The four client surfaces that originate outbound integration traffic: the React/Vite dashboard (apps/dashboard, MapLibre GL + socket.io-client), and the Flutter student and driver apps (apps/student_app, apps/driver_app, shared config in packages/naql_app/lib/src/config.dart, API + Socket.IO client in packages/naql_core). Web builds call the API at same-origin `/api/` (nginx proxy); mobile builds use --dart-define=API_URL (demo builds let the user change the server address in-app). Internal component structure is documented in other perspectives.
