Self-hosted runtime defined by docker-compose.yml (local stack and base for production) and the public-server overlay in deploy/oracle/. Default services: postgres, redis, the OSRM trio, api, dashboard (port 8080), student-web (8081), driver-web (8082). Opt-in profiles: `https` (Caddy + Let's Encrypt), `backup` (nightly pg_dump), `observability` (Prometheus :9090, Grafana :3001, Jaeger :16686/4318). Production runs on an Oracle Cloud Ampere (ARM) VM via `./deploy/oracle/up.sh`; all images are multi-arch.
