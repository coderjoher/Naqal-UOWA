Production overlay for Oracle Cloud (or any VM). deploy/oracle/up.sh checks that .env exists, then runs `docker compose -f docker-compose.yml -f deploy/oracle/compose.server.yml --profile https --profile backup up -d --build --wait`. compose.server.yml requires DB_PASSWORD and JWT_SECRET (`:?` guards), rewrites DATABASE_URL for api and backup, removes every published port with `ports: !reset []` (only Caddy 80/443 stay reachable) and adds `restart: unless-stopped` everywhere. deploy/oracle/env.example provides DuckDNS domains, ACME_EMAIL, DEMO=true, API_WORKERS=3 (4-core Ampere) and empty map-tile settings.
