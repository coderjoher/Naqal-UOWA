`backup` service (profile backup, enabled by up.sh): image from infra/backup/Dockerfile (postgres:16-alpine + rclone + tzdata). backup.sh loops until BACKUP_HOUR Baghdad time, dumps to ./backups, verifies, prunes after BACKUP_KEEP_DAYS (14) and optionally rclone-copies to BACKUP_REMOTE. `docker compose run --rm backup now` takes an immediate backup; restore-drill.sh is exercised in CI.
