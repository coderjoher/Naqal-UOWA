Three nginx containers: `dashboard` (apps/dashboard/Dockerfile + apps/dashboard/nginx.conf; Vite build with VITE_MAP_TILES / VITE_MAP_ATTRIBUTION build args) and `student-web` / `driver-web` (infra/flutter-web/Dockerfile with APP arg, Flutter web build, infra/flutter-web/nginx.conf; student-web also gets MAP_TILES args). Each serves its SPA, adds hardening headers (Permissions-Policy, COOP; camera/geolocation allowed for the Flutter apps), and proxies `/api/` to api:3000 with WebSocket upgrade for Socket.IO at /api/socket.io/ (1 h read timeout).
