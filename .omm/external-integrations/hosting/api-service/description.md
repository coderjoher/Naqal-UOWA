`api` service built from apps/api/Dockerfile (NestJS). Env: DATABASE_URL, REDIS_URL, OSRM_URL, JWT_SECRET, DEMO_SEED and OTP_DEV_ECHO (both from DEMO, default true), STORAGE_DIR=/data/storage (driver documents in the `storage` volume), API_WORKERS (one process per core), METRICS_TOKEN, SENTRY_DSN, OTEL_EXPORTER_OTLP_ENDPOINT. Ports 3000 (HTTP, /docs) and 9464 (aggregated Prometheus metrics). Healthcheck fetches /health. Outbound integrations from here: university identity, FCM, Sentry, OTLP.
