Placeholder for an SMS provider used for driver phone sign-in OTPs. apps/api/src/drivers/otp.service.ts defines the SmsSender interface and ConsoleSmsSender; app.module.ts binds SMS_SENDER to ConsoleSmsSender, which only logs the Arabic message with the 6-digit code. Codes: bcrypt-hashed, 5 min TTL, 60 s resend limit, 5 attempts. With OTP_DEV_ECHO=true (DEMO=true) the code is returned to the app and shown on screen instead.
