Automatic TLS certificates. The `https` compose profile runs caddy:2.9-alpine with infra/caddy/Caddyfile: global `email {$ACME_EMAIL}`, one site block per DASHBOARD_DOMAIN / STUDENT_DOMAIN / DRIVER_DOMAIN reverse-proxying to dashboard:80, student-web:80, driver-web:80, with zstd/gzip, HSTS (1 year, includeSubDomains) and the Server header removed. Certificates persist in the `caddy` volume.
