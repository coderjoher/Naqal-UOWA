Socket.IO gateway (apps/api/src/live/live.gateway.ts) behind RedisIoAdapter (redis-io.adapter.ts). On connect it verifies the JWT, loads the user (as system) and joins user:{id}, plus ops:{uni} for office users and driver:{id} for drivers. `join`/`leave` let a student join only run:{id} of their own ride and reply with the last known position; `gps` forwards driver points to LiveService.ingest.
