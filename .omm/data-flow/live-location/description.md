Live bus tracking pipeline (apps/api/src/live/). GPS points arrive from the driver app via Socket.IO `gps` or POST /runs/:id/gps (buffered batches). LiveService.ingest sanitizes them, keeps the newest point in Redis (hash live:last:{runId}, GEO set live:geo:{uni}), broadcasts `bus` (position + ETAs per remaining stop) to run:{id} and ops:{uni} rooms, persists only one RunPosition per run per minute plus the first point near each stop and campus (proof for settlement), and drafts "bus about 5 minutes away" notifications. Students read the last position on `join` (NF-10) or GET /rides/:id/track.
