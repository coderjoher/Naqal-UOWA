Redis keys owned by LiveService: `live:last:{runId}` hash {lat,lng,at,speed,heading}, TTL 24 h (newest position, used by join/track); `live:geo:{universityId}` GEO set of run positions; `live:pos:{runId}:{epochMinute}` dedupe markers, TTL 6 h (one stored point per minute, even for points replayed after an offline gap); `live:near:{runId}:{seq|campus}` markers, TTL 6 h (first point at each stop is always stored).
