LiveHub (apps/api/src/live/live.hub.ts): thin emitter used by services. Rooms: run:{id}, ops:{uni}, user:{id}, driver:{id}, taxi:{uni}. Events: `bus`, `run` (status), `run:updated` (refetch), `notification`, `taxi:ride`, `taxi:gone`, `taxi:offer`, `taxi:position`. BullMQ processors run inside the same API processes (cluster workers, API_WORKERS), so emits from jobs also go out; the Redis Socket.IO adapter (pub/sub channel prefix `{QUEUE_PREFIX}:io`) carries each emit to sockets on every process. Without an attached server (unit tests) emits are dropped.
