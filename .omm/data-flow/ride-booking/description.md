RidesService.request (apps/api/src/dispatch/rides.service.ts, POST via rides.controller.ts). Validates the student (active, gender known), the date (today or tomorrow, Baghdad time), the wave (active, runs that weekday, not yet left) and the gathering point. Computes the fare at request time: subscribers with an active subscription covering the date ride free in their registered tier or pay the tier difference (pricing.ts tierDifference); non-subscribers pay the point tier's ridePrice. Inserts one RideRequest (status open) carrying tierId, gender, subscriber flag and fare. If the wave/date already has a WavePlan, it enqueues a `waitlist.recheck` job so the new request is inserted into an existing run. Cancellation goes through DispatchEngine.cancel. Also serves drivers' availability (DriverAvailability rows, up to 7 days ahead, bus drivers only).
