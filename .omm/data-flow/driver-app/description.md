Flutter driver app (apps/driver_app/). Produces: OTP sign-in, application fields and document uploads (multipart), bus availability per wave/date, run actions (start, arrive, board, no-show, end), GPS fixes every 5 s while a run is under way, cash fare confirmations, and for taxi drivers heartbeats with position plus accept/arrive/start/end. Run actions, GPS and fares go through a persistent outbox (packages/naql_core/lib/src/sync_queue.dart, stored in preferences under `naql.outbox`) so offline periods are replayed later with their original timestamps and client ids.
