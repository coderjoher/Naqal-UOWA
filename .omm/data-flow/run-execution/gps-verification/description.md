SettlementService.verifyRun + verifyTrack (apps/api/src/settlement/settlement.service.ts, verify.ts; SE-02/NF-15). Reads the run's stored RunPositions, stops and campus location and checks the track proves the run (visited stops, reached campus, plausible speed). Stores Run.gpsVerified and Run.gpsFlags (e.g. "missed_stop:2", "too_fast"). Called when a run ends and again for every run without an office verdict when a month's settlement is computed; the office can override with Run.officeVerdict.
