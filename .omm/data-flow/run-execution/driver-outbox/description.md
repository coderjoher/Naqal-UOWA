SyncQueue + JsonOutboxStore in the shared Flutter core (packages/naql_core/lib/src/sync_queue.dart), wired in apps/driver_app/lib/data/run_controller.dart. Every driver action, GPS fix (every 5 s while the run is under way) and fare is an OutboxItem {id (uuid clientId), kind gps|action|fare, runId, payload, createdAt}, persisted as JSON in app preferences (`naql.outbox`) so it survives restarts, and flushed periodically to the API. The client id makes server-side replays idempotent (NF-09).
