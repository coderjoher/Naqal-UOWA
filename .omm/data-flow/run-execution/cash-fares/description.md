RunsService.fare (apps/api/src/runs/runs.service.ts, DR-07/PA-03). The driver confirms cash for one boarded rider; the amount is the fare frozen on the RideRequest (ride price or tier difference; 0 for covered subscribers is refused). Calls PaymentsService.record in a transaction with type cash_fare, method cash_driver, runId, rideRequestId and idempotencyKey = outbox clientId. An existing payment for the clientId or rideRequestId is returned as duplicate; a racing retry's unique violation (P2002) is resolved the same way.
