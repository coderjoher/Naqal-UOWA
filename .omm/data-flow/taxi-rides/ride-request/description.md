TaxiService.request + offer (TX-01/TX-02). Returns the existing ride for a repeated clientId; refuses a second active ride; re-quotes; inserts TaxiRide (direction, student lat/lng/label, distanceKm, fare, clientId, expiresAt = now + taxiOfferSeconds). offer() picks nearby free online drivers, writes `taxi.offer` notifications (dedupe per ride, driver and offer round) via addNow, and emits a `taxi:offer` card to each driver. cancelByStudent cancels and emits `taxi:gone`; cancelByDriver puts the ride back to requested with a fresh expiry and re-offers it.
