Redis hash `taxi:online:{universityId}` (field = driverId, value = JSON {lat, lng, at}). TaxiService.heartbeat HSETs it on every driver heartbeat and joins the driver's sockets to the taxi:{uni} room; goOffline HDELs it. online() HGETALLs and keeps only entries fresher than ONLINE_STALE_MS (60 s); driversToOffer filters out busy drivers and those farther than OFFER_RADIUS_KM (8 km). While a trip is active the heartbeat also emits `taxi:position` with an ETA to the student.
