TaxiService.accept / arrive / start (TX-02..TX-04). accept: driver must be an approved taxi driver with no busy ride; a conditional updateMany (status requested and not expired -> accepted, driverId, acceptedAt) decides the single winner, and a `taxi.accepted` notification is written in the same transaction; then `taxi:gone` tells other drivers to drop the card and `taxi:ride` refreshes student, driver and ops. arrive sets arrivedAt (+ `taxi.arrived` notice); start sets startedAt and status on_trip.
