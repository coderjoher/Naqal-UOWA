NotificationsService.deliverPending(universityId) (apps/api/src/notifications/notifications.service.ts). Under the tenant context: loads up to 200 rows with pushedAt null, claims them with updateMany(pushedAt null -> now) so concurrent callers never send twice, loads recipients' DeviceTokens, emits LiveHub.toUser(`notification`) and sends one push per token. Errors are logged, never thrown to the caller. addNow() = add outside a transaction + deliverPending.
