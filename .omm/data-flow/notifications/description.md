Transactional outbox for user messages (apps/api/src/notifications/). Business code turns domain events into NotificationDrafts with rules.ts notificationsFor (ride.assigned, ride.waitlisted, ride.bumped, ride.expired, ride.cancelled, ride.approaching, ride.arrived, ride.moved, run.changed, announcement, problem.answered, taxi.offer/accepted/arrived/cancelled...) and writes them as Notification rows inside its own transaction (NotificationsService.add, skipDuplicates on the unique dedupeKey). After commit deliverPending claims undelivered rows (pushedAt = now), emits a socket `notification` to user:{id}, and sends an Arabic title/body via FCM to each DeviceToken; invalid tokens are deleted. Apps list and mark-read via GET /notifications/me and POST /notifications/read.
