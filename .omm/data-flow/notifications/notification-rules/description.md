Pure functions in apps/api/src/notifications/rules.ts. notificationsFor(event) maps dispatch, run and ETA events to drafts {userId, kind, dedupeKey, data}; dedupe keys like `assigned:{requestId}:{runId}`, `approaching:{requestId}`, `arrived:{requestId}` guarantee each event notifies once. messageFor(kind, data, 'ar') renders the Arabic push title/body. Other producers (DispatchEngine.move/extraRun, TaxiService, announcements, feedback) build drafts directly.
