DispatchEngine.locked + load + save (apps/api/src/dispatch/dispatch.engine.ts). load() reads University (waitlistMinutes), Wave, DistanceTiers (rank), live Runs with stops and assigned/no-show requests, and open/assigned/waitlisted RideRequests, then builds the domain context (wave time, travel function, now). save() upserts Runs (create or update tierId/capacity), rewrites RunStops with ETAs, sets RideRequest status assigned/runId (only for still-seatable rows), deletes runs left empty, marks waitlisted requests with waitlistedUntil, cancels expired ones (cancelReason 'expired'), and writes Notification drafts via NotificationsService.add (createMany skipDuplicates on dedupeKey). Also handles office operations move() (TO-08) and extraRun().
