Precomputed OSRM travel matrix (apps/api/src/routing/). RoutingService.scheduleMatrixRebuild enqueues `rebuild-matrix` on the routing BullMQ queue when gathering points change; TravelMatrixProcessor calls the OSRM table API for campus + all active points and replaces the university's TravelTime rows (durationS, distanceM) in one transaction. The dispatch engine and LiveService ETA calculation read these rows; missing pairs fall back to straight-line distance x 1.3 at 30 km/h.
