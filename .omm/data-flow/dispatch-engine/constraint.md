Every operation on a wave/date runs in one Prisma interactive transaction (timeout 60 s, maxWait 30 s) that first takes `pg_advisory_xact_lock(hashtext('dispatch:{waveId}:{date}'))`. Run actions from drivers reuse the same lock (DispatchEngine.locked), so boarding never interleaves with re-planning. A wave is planned once (WavePlan row, primary key (waveId, date)); later calls fall through to recheck. Taxi drivers are excluded from bus planning (BUS_ONLY filter).
