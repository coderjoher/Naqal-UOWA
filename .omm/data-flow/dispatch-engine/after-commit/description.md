DispatchEngine.afterCommit (apps/api/src/dispatch/dispatch.engine.ts). Runs only after the locked transaction commits: invalidates the officeViews SWR cache, schedules a delayed `waitlist.expire` job for each new or changed waitlistedUntil, emits `run:updated` via LiveHub to run:{id}, ops:{uni} and driver:{id} rooms for each changed run (DR-09, clients refetch), and calls NotificationsService.deliverPending for the university.
