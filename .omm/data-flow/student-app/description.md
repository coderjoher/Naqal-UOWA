Flutter student app (apps/student_app/). Data sources it produces: ride requests for a wave/date/gathering point, cancellations, taxi quotes/requests (with the student's lat/lng and a client-generated clientId), ratings and problem reports, FCM device token registration. Data it consumes: its own requests with assignment details (driver, plate, vehicle photo via signed link), live bus position + ETAs by joining the Socket.IO room run:{id}, taxi position updates, and notifications (socket `notification` event + push).
