PaymentsService.record(tx, input) (apps/api/src/payments/payments.service.ts): the single write path for money. Validates a positive integer amount, calls provider(method).collect, takes nextReceiptNo(tx, universityId), and creates the Payment with type, method, amount, receiptNo, studentId, collectedById, externalRef, optional runId / rideRequestId / taxiRideId and idempotencyKey. It never opens its own transaction, so the caller's related rows (Subscription, TaxiRide end state) commit or roll back together with the money.
