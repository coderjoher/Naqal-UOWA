PaymentsService.reverse (POST via subscriptions.controller.ts, office only). Requires a reason; refuses reversing a reversal or an already reversed payment. In one transaction creates a new Payment with the negated amount, same type/method/student, a new receipt number, reversesPaymentId = original, note = reason, and sets any Subscription linked to the original to cancelled. Settlement nets reversals by following reverses.runId / reverses.taxiRide.
