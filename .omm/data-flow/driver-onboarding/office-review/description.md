DriversService.list / detail / review (GET drivers, GET drivers/:id, POST drivers/:id/approve|reject|suspend|reinstate). Office users see the application and documents; review moves the DriverProfile status through nextStatus (draft -> pending -> approved / rejected / suspended), requiring a note for reject and suspend, and stores reviewedAt, reviewedById, reviewNote. Approved, non-taxi drivers with seats become eligible for bus planning; approved taxi drivers for taxi offers.
