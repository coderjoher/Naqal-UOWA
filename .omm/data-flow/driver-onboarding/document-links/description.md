DriversService.documentLink (POST drivers/:id/documents/:key/link; also used for the vehicle photo in a student's assignment) issues a token = base64url({k: storageKey, m: mime, e: exp}) + HMAC-SHA256 signature (STORAGE_SECRET, default JWT_SECRET + ':files'), valid at most 5 minutes, and logs a DocumentAccess row (document, viewer, expiresAt). With reuse, a still-valid logged link for the same viewer is re-signed instead of logging a new access. FilesController GET /files/:token (public route) verifies the signature and expiry and streams the bytes with `cache-control: private, no-store`; invalid or expired tokens get 404.
