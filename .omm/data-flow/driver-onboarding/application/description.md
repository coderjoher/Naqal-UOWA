DriversService.mine / update / submit (GET drivers/me, PATCH, POST drivers/me/submit). mine upserts the DriverProfile and reports status, review note, application fields, uploaded documents and what is still missing (missingRequirements vs the university's requirements). update writes User.name and DriverProfile vehicle fields while the application is editable (draft/rejected). submit refuses with the missing list until complete, then sets status pending and submittedAt.
