OtpService + DriversService.requestOtp/verifyOtp (POST auth/driver/otp, auth/driver/verify). Normalizes an Iraqi mobile number; issues a 6-digit code (crypto randomInt), stores only its bcrypt hash in OtpCode (one row per phone, 5 min TTL, attempts counter; dies after 5 wrong guesses) and sends it via the SMS sender. verify consumes the row once; finds the User by loginPhone or, on first login, creates User (role driver) + DriverProfile (draft) in the university chosen by slug; returns a JWT. Rate-limited per phone and IP (security/rate-limit.ts, Redis counters). OtpCode is not tenant-scoped.
