RedisIoAdapter (apps/api/src/live/redis-io.adapter.ts), installed in setup-app.ts when REDIS_URL is set: @socket.io/redis-adapter over a dedicated ioredis pub connection and its duplicate for sub, channel key `{QUEUE_PREFIX}:io`. Lets every API cluster worker emit to sockets connected to any other worker (bus positions, run changes, notifications, taxi events) without sticky sessions. Pure pub/sub: nothing is stored.
