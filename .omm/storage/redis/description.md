Redis 7 (redis:7-alpine, REDIS_URL). Three kinds of clients: the global ioredis client REDIS (apps/api/src/redis/redis.module.ts; lazyConnect, maxRetriesPerRequest 1) used by caches, rate limits, live tracking, taxi presence and health checks; BullMQ connections (app.module.ts BullModule.forRootAsync, key prefix QUEUE_PREFIX default `naql`); and a pub/sub pair for the Socket.IO Redis adapter (apps/api/src/live/redis-io.adapter.ts, key `{QUEUE_PREFIX}:io`). Everything stored here is transient or reconstructible; PostgreSQL remains the source of truth.
