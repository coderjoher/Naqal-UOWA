ConfigCache (apps/api/src/config-cache/config-cache.service.ts, NF-04): keys `cfg:{universityId}:{tiers|points|waves|driver-requirements}` holding JSON, TTL 3600 s. get() returns the cached value or runs the loader and stores it; invalidate() DELs after writes in tiers, points, waves and driver-requirements services. Every Redis error is logged and the loader is used, so a cache outage never breaks the API.
