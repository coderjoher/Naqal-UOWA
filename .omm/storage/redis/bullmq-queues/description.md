BullMQ (@nestjs/bullmq) configured in apps/api/src/app.module.ts from REDIS_URL (host, port, password, db index) with prefix QUEUE_PREFIX (default `naql`). Queues: `dispatch` (wave.tick scheduler every 60 s, wave.plan, waitlist.recheck, waitlist.expire delayed jobs; processor dispatch/dispatch.processor.ts), `taxi` (taxi-sweep scheduler every 20 s; taxi/taxi.processor.ts), `routing` (travel-matrix.rebuild with jobId matrix-{uni}, 2 s delay; routing/travel-matrix.processor.ts). Completed jobs removed, last 20-100 failures kept. Dispatch queue counts (waiting, active, delayed, failed) are exported as the Prometheus gauge naql_queue_jobs (observability/metrics.ts).
