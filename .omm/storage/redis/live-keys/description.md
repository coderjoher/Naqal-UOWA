Owned by LiveService (apps/api/src/live/live.service.ts, NF-01): `live:last:{runId}` hash (lat, lng, at, speed, heading; TTL 24 h) = newest bus position, read on join/track with RunPosition as fallback; `live:geo:{universityId}` GEO set of run positions (no TTL); `live:pos:{runId}:{epochMinute}` and `live:near:{runId}:{seq|campus}` SET NX markers (TTL 6 h) that decide which GPS points are persisted to Postgres (one per minute + first point at each stop/campus).
