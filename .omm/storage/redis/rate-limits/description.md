RateLimitGuard (apps/api/src/security/rate-limit.ts): fixed-window counters `rl:{rule}:{ip}:{fields}:{window}` via MULTI INCR + EXPIRE (window + 5 s). Rules: login-account 10/10 min and login-ip 300/10 min; otp-phone 5/h and otp-ip 60/h (plus others declared with @RateLimit). Exceeding returns 429 with Retry-After. RATE_LIMIT_FACTOR multiplies limits for load tests. Shared across cluster workers because it lives in Redis.
