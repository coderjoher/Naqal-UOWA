DriverProfile (driver_profiles, PK userId): application + vehicle (vehicleType, plate, seats, modelYear) and review state draft|pending|approved|rejected|suspended with reviewer and note. DriverDocument (driver_documents, unique driverId+key): pointer to the private file (storageKey, mime, sizeBytes, uploadedAt); bytes live in file storage. DocumentAccess (document_accesses): audit log of every signed link issued (document, viewer, expiresAt) for NF-13. DriverAvailability (driver_availability, PK driverId+date+waveId): which waves a bus driver offers to run on which dates (DR-02), read by wave planning.
