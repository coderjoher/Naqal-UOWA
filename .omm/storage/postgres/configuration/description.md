Rarely changing per-university transport configuration, cached in Redis (cfg:{uni}:tiers|points|waves|driver-requirements, 1 h TTL, invalidated on write). DistanceTier (distance_tiers): contiguous km bands with subscriptionPrice and ridePrice in IQD. GatheringPoint (gathering_points): fixed pickup points with lat/lng, tier (derived from OSRM road distance unless tierOverridden), distanceKm/durationMin, active. Wave (waves): morning arrive-by or return departure minuteOfDay (Asia/Baghdad) with a weekday bit mask. DriverRequirementSet (driver_requirement_sets, one per university): required documents JSON, allowed vehicle types, minSeats, maxVehicleAgeYears. TravelTime (travel_times, PK universityId+fromKey+toKey): OSRM duration/distance between points and "campus", fully replaced by the routing worker.
