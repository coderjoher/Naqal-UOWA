PostgreSQL 16 (Docker image postgres:16-bookworm, volume pgdata; DATABASE_URL), accessed only through Prisma (apps/api/prisma/schema.prisma, 10 migrations under apps/api/prisma/migrations from init to p10_taxi). 31 models grouped below by domain. Tenancy (NF-05): every tenant-owned table has a university_id column; PrismaService.db is `new PrismaClient().$extends(tenantExtension)`, which adds `universityId` to the where clause of reads/updates/deletes and stamps it on creates for the 28 models in TENANT_MODELS, using the AsyncLocalStorage tenant context set per request (tenant.middleware.ts) or by runAsTenant / runAsSystem in jobs. Not tenant-scoped: University, ReceiptCounter, OtpCode (and AuditEvent.universityId / User.universityId are nullable for platform-level super admin rows). Postgres also provides advisory transaction locks (dispatch per wave/date) and immutability triggers for money.
