RideRequest (ride_requests): one student, wave, date, gathering point, tier, gender, subscriber flag, frozen fare, status open|assigned|waitlisted|cancelled|done|no_show, runId, waitlistedUntil, cancelReason, boardedAt; partial unique index ride_requests_one_live (student, wave, date) for live statuses. Run (runs, unique driverId+waveId+date): one bus for one wave/date with gender, tierId (farthest stop), capacity, status planned|started|at_stop|done|cancelled, start/end times, gpsVerified, gpsFlags JSON, officeVerdict/officeNote. RunStop (run_stops, unique runId+seq): ordered stops with eta, arrivedAt, servedAt (cascade with run). WavePlan (wave_plans, PK waveId+date): marks a wave/date as planned. RunEvent (run_events, unique runId+clientId): idempotent log of driver actions with device time. RunPosition (run_positions, index runId+at): GPS track sampled to one point per minute plus stop proofs.
