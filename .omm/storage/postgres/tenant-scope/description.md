Tenant isolation layer (apps/api/src/tenancy/). tenant.middleware.ts opens an empty AsyncLocalStorage store per request; the JWT auth guard fills universityId/userId/role (super admins get global). tenant-scope.ts scopeArgs is a pure function applied by a Prisma `$allModels.$allOperations` extension: for models in tenant-models.ts it adds `universityId` to where (find*, count, aggregate, groupBy, update*, delete*, upsert), stamps it on create/createMany/upsert-create, throws CrossTenantWriteError when data names another university and TenantContextMissingError when no context exists. Global context (runAsSystem) skips filtering; runAsTenant is used by jobs and the live pipeline.
