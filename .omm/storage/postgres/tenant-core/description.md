University (universities): name/nameAr, unique slug, campus lat/lng, commissionPct, waitlistMinutes, noShowWaitMinutes, integrationConfig JSON (identity provider), coverage polygon JSON, officeNote, taxi switches and tariff (taxiEnabled, taxiBaseFare, taxiPerKm, taxiMinFare, taxiOfferSeconds). Not tenant-scoped (it is the tenant). User (users): role student|driver|office|super_admin, universityId (null only for super_admin), unique email, unique loginPhone (driver OTP), studentId unique per university, gender, passwordHash, status, defaultPointId. AuditEvent (audit_events): actor, action, entity, entityId, payload JSON; written by audit.interceptor.ts and AuditService for office actions such as settlement approval and run verdicts.
