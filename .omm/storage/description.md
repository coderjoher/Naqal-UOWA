Storage topology of the Naql platform. PostgreSQL 16 (via Prisma, apps/api/prisma/schema.prisma) is the single source of truth for all business records, multi-tenant by a universityId column enforced by a Prisma client extension. Redis 7 holds everything transient: BullMQ queues, live GPS state, online taxi presence, Socket.IO pub/sub, a configuration cache and rate-limit counters. Driver documents are files on a private disk volume behind HMAC-signed links. Each API process additionally keeps short-lived in-memory caches. The driver app keeps an offline outbox on the device. A backup container dumps PostgreSQL nightly with optional off-site copy and a restore drill.
