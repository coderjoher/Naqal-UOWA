The NestJS API (apps/api/src/, entry main.ts / setup-app.ts), one or more cluster processes (API_WORKERS). It is the only component that talks to the stores: PrismaService (prisma/prisma.service.ts) for PostgreSQL, the global REDIS ioredis client (redis/redis.module.ts), BullMQ (configured in app.module.ts from REDIS_URL with prefix QUEUE_PREFIX, default `naql`), RedisIoAdapter for Socket.IO, and StorageService for files. BullMQ processors (dispatch, taxi, routing) run inside these same processes.
