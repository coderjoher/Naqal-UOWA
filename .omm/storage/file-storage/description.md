Private document storage (apps/api/src/storage/storage.service.ts, NF-13). Local filesystem under STORAGE_DIR (default ./storage; /data/storage in Docker on the named volume `storage`), created with mode 0700; files written 0600 at key `drivers/{universityId}/{driverId}/{uuid}`. Holds driver documents and vehicle photos uploaded through PUT drivers/me/documents/:key (JPEG/PNG/WebP/PDF, max 8 MB). Never served statically: GET /files/:token verifies an HMAC-SHA256 token (STORAGE_SECRET, default JWT_SECRET + ':files') carrying key, mime and expiry (max 5 minutes) and streams the bytes with no-store caching. Metadata and access logs live in Postgres (DriverDocument, DocumentAccess). The service is written so an S3/MinIO adapter can replace the disk backend.
