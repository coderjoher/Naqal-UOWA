On-device storage in the driver app: SyncQueue with JsonOutboxStore (packages/naql_core/lib/src/sync_queue.dart), persisted as one JSON value under the preferences key `naql.outbox` (apps/driver_app/lib/data/run_controller.dart). Holds run actions, GPS fixes and fare confirmations made offline, each with a uuid client id, until they are flushed to the API (NF-09). The server makes replays idempotent with RunEvent (runId, clientId), Payment.idempotencyKey and per-minute GPS dedupe keys.
