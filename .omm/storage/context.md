Docker Compose (docker-compose.yml) runs postgres:16-bookworm (volume pgdata), redis:7-alpine (no volume, no persistence config), the api with STORAGE_DIR=/data/storage on volume `storage`, and an optional `backup` profile (infra/backup) writing to ./backups. deploy/oracle/compose.server.yml hides all ports except Caddy, sets the DB password, and up.sh starts the stack with `--profile https --profile backup`. The API runs API_WORKERS cluster processes; all share Postgres and Redis, so cross-process state (queues, sockets, rate limits) must live in Redis, never in memory.
