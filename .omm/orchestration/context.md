BullModule.forRootAsync (app.module.ts) parses REDIS_URL and uses prefix QUEUE_PREFIX (default 'naql'); queues DISPATCH_QUEUE='dispatch' and TAXI_QUEUE='taxi' are registered in AppModule, ROUTING_QUEUE='routing' in RoutingModule. The Socket.IO server uses RedisIoAdapter (setup-app.ts, only when REDIS_URL is set) with key '{QUEUE_PREFIX}:io'. The pattern throughout is: mutate inside a DB transaction (writing outbox rows), then after commit fan out (sockets, push, cache invalidation, follow-up jobs).
