Transactional outbox for user notifications (ST-07/ST-09). Business code writes Notification rows inside its own transaction (NotificationsService.add, deduplicated by unique dedupeKey via createMany skipDuplicates) or immediately (addNow). After commit, deliverPending sends every undelivered row of the tenant: a 'notification' socket event to user:{id} via LiveHub.toUser and an FCM push to each registered device token. The in-app list (GET notifications, markRead) reads the same table.
