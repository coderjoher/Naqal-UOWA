NotificationDraft.kind is one of: ride.assigned, ride.waitlisted, ride.approaching, ride.arrived, ride.cancelled, ride.bumped, ride.expired, ride.moved, run.changed, announcement, problem.answered, taxi.offer, taxi.accepted, taxi.arrived, taxi.cancelled, taxi.expired. notificationsFor(RideEvent) maps assigned / waitlisted / bumped / expired / cancelled / eta / arrived to drafts with stable dedupe keys (e.g. assigned:{requestId}:{runId} so a bus change is news again, approaching:{requestId} once per ride when ETA <= APPROACHING_S = 300 s). messageFor(kind, lang) renders Arabic/English push text.
