DispatchEngine (dispatch/dispatch.engine.ts): glue between the pure dispatch domain (dispatch/domain/) and Postgres. Public ops plan, recheck, cancel, move, extraRun plus locked() (also used by RunsService). save() diffs runs and stops, re-assigns riders with the race-safe status filter (open/waitlisted/assigned only), deletes empty runs, records waitlist and expiries, and writes the outbox. afterCommit() fans out: officeViews.invalidate, waitlist.expire jobs, hub.runChanged, notifications.deliverPending.
