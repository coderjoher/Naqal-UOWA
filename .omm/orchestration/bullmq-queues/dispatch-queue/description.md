Queue 'dispatch' (DISPATCH_QUEUE) consumed by DispatchProcessor (dispatch/dispatch.processor.ts), which switches on job.name: wave.plan -> DispatchEngine.plan, waitlist.recheck and waitlist.expire -> DispatchEngine.recheck, wave.tick -> tick(). All engine work for one wave+date runs in a Postgres transaction holding pg_advisory_xact_lock('dispatch:{waveId}:{date}') (timeout 60 s, maxWait 30 s), then afterCommit() soft-invalidates officeViews, schedules waitlist.expire jobs, emits LiveHub.runChanged for each changed run and calls NotificationsService.deliverPending.
