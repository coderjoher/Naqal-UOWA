LiveGateway: on connect verifies auth.token (or ?token) and requires an active user with a university, then joins user:{id}, plus ops:{universityId} for office and driver:{id} for drivers, and emits 'ready'; failures emit 'error' and disconnect. Messages: 'join' {runId} (office any run of the tenant, driver own run, student only a run where their request is assigned/done; reply carries last bus position, NF-10), 'leave', 'gps' (driver only, forwarded to LiveService.ingest).
