LiveService (live/live.service.ts), NF-01: accepts driver GPS (socket 'gps' or POST /runs/:id/gps) only from the run's driver while started/at_stop. Stores the last point (hash live:last:{runId}) and GEO set live:geo:{uni} in Redis, persists one RunPosition per run-minute plus the first point near each stop/campus (SET NX buckets), broadcasts hub.bus with ETAs, and adds ride.approaching notifications when a rider's stop is within 5 minutes. Keeps a 15 s per-run route cache, invalidated by RunsService.act.
