Signed-out driver flow in apps/driver_app/lib/screens/onboarding/: `/welcome` (welcome_screen.dart) -> `/university` (university_screen.dart, choose the university) -> `/phone` (phone_screen.dart, enter mobile number; API issues an SMS OTP) -> `/code` (code_screen.dart, enter the 6-digit code; back goes to /phone). Once verified, applicationProvider holds a draft/existing application and the redirect leaves onboarding.
