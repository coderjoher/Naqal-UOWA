Layout route without a path: `<RequireAuth><Shell/></RequireAuth>` (apps/dashboard/src/app/guards.tsx, app/Shell.tsx). RequireAuth redirects to /login when there is no session; Shell renders the navigation rail/flyouts from visibleNav() and an <Outlet/> for child pages. Its index route is OverviewPage (`/`, roles office + super_admin). RequireRole wraps each child and uses RedirectOnce (fires a single navigate) so exit animations do not cause redirect loops.
