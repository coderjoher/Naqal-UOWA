React Router (v7 `react-router`, BrowserRouter) route tree of the office dashboard, defined in apps/dashboard/src/app/App.tsx (AppRoutes). Navigation chrome is generated from apps/dashboard/src/app/nav.ts: five NavGroups rendered either as individual rail buttons (`display: 'rail'`) or as a single rail button opening a popover (`display: 'flyout'`). `visibleNav(can)` filters items by role, so a super_admin sees Overview, Universities and Audit only, while office users see everything except Universities. app/Search.tsx offers page search over ALL_ITEMS.
