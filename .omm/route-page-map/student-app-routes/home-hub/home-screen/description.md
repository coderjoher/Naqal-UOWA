HomeScreen (screens/home_screen.dart): map with the default point and ride cards (screens/ride_cards.dart, subscription_card.dart). Entry point for every other screen: header buttons push /profile and /alerts; the point chip pushes /profile/point; booking cards push /bus with optional dir/wave/date query; an active taxi pushes /taxi?ride=; an active bus ride goes to /home/track/:id.
