live/live.hub.ts: injectable emitter holding the Socket.IO server once the gateway initialises (emits are dropped in tests/workers without it). Rooms: run:{id}, ops:{universityId}, user:{id}, driver:{id}, taxi:{universityId}. Only bus positions are broadcast, never student locations (NF-12). live/redis-io.adapter.ts: @socket.io/redis-adapter on ioredis pub/sub (key {QUEUE_PREFIX}:io) so emits from any worker reach sockets on every worker.
