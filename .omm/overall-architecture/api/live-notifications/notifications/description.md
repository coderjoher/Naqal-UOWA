notifications/notifications.service.ts: persists Notification rows, emits `notification` to the user's socket room via LiveHub and sends a push to every registered DeviceToken through PUSH_SENDER (invalid tokens are deleted); also registers device tokens and marks notifications read. rules.ts decides which riders at which stops to alert as the bus approaches; push.ts provides FcmPushSender (FCM HTTP v1, cached OAuth token) and LogPushSender.
