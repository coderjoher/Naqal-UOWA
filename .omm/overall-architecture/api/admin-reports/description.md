Office-facing communication and analytics, all exposed through feedback/feedback.controller.ts. feedback/: ride ratings and problem reports from students/drivers (the dashboard Inbox). announcements/: targeted announcements (whole university or one gathering point) delivered as push + in-app banner until expiry via NotificationsService. reports/: monthly KPI report (reports.service.ts + metrics.ts computeReport) over runs, ride requests, payments and ratings, optionally per tier, aligned with settlement months; CSV/XLSX export happens in the dashboard. Audit log browsing reads AuditEvent rows written by the AuditInterceptor.
