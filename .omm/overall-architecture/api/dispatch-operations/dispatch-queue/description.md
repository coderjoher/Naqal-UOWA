dispatch/dispatch.processor.ts: BullMQ WorkerHost on queue `dispatch`. On init (unless DISPATCH_TICK=off) upserts a job scheduler `wave-tick` every 60 s that plans every wave whose planning time has come; also handles wave.plan (jobId plan-{wave}-{date}, 3 attempts with backoff), waitlist.recheck and waitlist.expire. Runs under runAsSystem / runAsTenant since there is no HTTP request context (NF-03: never on the request path).
