The core bus operation. waves/: daily departure slots (direction, time, planning lead) per university. dispatch/: students' RideRequests (rides.controller/service, the office dispatch board), DispatchEngine (plans waves into Runs using the pure domain algorithm in dispatch/domain: cheapest insertion, subscriber priority, gender-separated runs, waitlist), DispatchProcessor on the `dispatch` BullMQ queue (wave.tick every 60 s, wave.plan, waitlist.recheck, waitlist.expire). runs/: driver run execution (idempotent actions by clientId, GPS batches, pay-per-ride fares, device tokens, notifications list) and the office live-ops view. routing/: OSRM client, RoutingService and TravelMatrixProcessor.
