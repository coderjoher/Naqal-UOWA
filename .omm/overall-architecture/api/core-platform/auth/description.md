auth/: AuthModule registers JwtModule (JWT_SECRET, JWT_TTL default 12h) and three global APP_GUARDs in order RateLimitGuard -> JwtAuthGuard -> RolesGuard. AuthController/AuthService handle email+password sign-in for office/super admin (students sign in via identity/, drivers via OTP in drivers/). decorators.ts provides @Public, @Roles, @CurrentUser. user-cache.ts keeps per-process caches of verified tokens and user status (AUTH_CACHE_MS, default 10 s). security/rate-limit.ts: Redis fixed-window counters per IP and account for login and OTP endpoints, 429 with Retry-After.
