Cross-cutting infrastructure every feature relies on: bootstrap (main.ts cluster + metrics server, setup-app.ts global pipeline), authentication and authorization (auth/, security/rate-limit.ts), multi-tenancy (tenancy/), data access (prisma/, redis/, config-cache/, common/swr-cache.ts), observability (observability/: OpenTelemetry, Sentry, Prometheus) and audit logging (audit/). Also health/health.controller.ts (public /health). The request-lifecycle perspective details how these pieces run per request.
