prisma/: global PrismaService exposing `db`, a PrismaClient extended with the tenant scope (type TenantPrisma; Tx for transactions). redis/: global ioredis client under the REDIS token (lazyConnect, maxRetriesPerRequest 1). config-cache/: ConfigCache, Redis cache `cfg:{universityId}:{tiers|points|waves|driver-requirements}` with 1 h TTL that falls back to the loader if Redis fails. common/swr-cache.ts: in-process stale-while-revalidate cache; `officeViews` (5 s fresh) serves the dispatch board and live-ops views and is invalidated by dispatch, runs and waves changes.
