NestJS 11 API (apps/api). One flat AppModule (app.module.ts) registers every controller and provider directly, plus feature modules for Auth, Prisma, Redis, Routing and a global ConfigCache module. main.ts optionally forks API_WORKERS cluster processes and serves Prometheus metrics on METRICS_PORT; setup-app.ts installs helmet, the Sentry exception filter, the global ValidationPipe and the Redis Socket.IO adapter. Background work (wave planning, waitlist re-checks, taxi expiry, travel matrix) runs in BullMQ processors inside the same processes. Swagger UI at /docs.
