React 19 + Vite single-page app for office staff and the super admin (apps/dashboard). Uses react-router 7, TanStack Query for REST data, socket.io-client for live updates, MapLibre for maps, Tailwind 4 with generated design tokens. Served by nginx (apps/dashboard/nginx.conf) which also reverse-proxies /api/* (REST and Socket.IO upgrade) to the API container, so the browser talks same-origin and a strict CSP applies.
