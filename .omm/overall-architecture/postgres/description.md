PostgreSQL 16 (postgres:16-bookworm container, volume pgdata). Schema and migrations live in apps/api/prisma (schema.prisma, migrations/, seed.ts, seed-demo.ts, seed-e2e.ts). Holds universities, users, roster, driver profiles/documents, tiers, gathering points, waves, ride requests, runs/stops/events/positions (one per run per minute), subscriptions, payments, settlements, taxi rides, notifications, audit events. 28 models carry universityId and are tenant-filtered (src/tenancy/tenant-models.ts). Backed up nightly by the optional backup profile (infra/backup).
