Redis 7 container shared by all API workers. Uses: BullMQ queues `dispatch`, `taxi` and routing travel-matrix jobs (prefix QUEUE_PREFIX, default naql); Socket.IO redis-adapter pub/sub (`naql:io`); sign-in rate-limit counters (`rl:*`); configuration cache (`cfg:{universityId}:{kind}`, 1 h TTL); live GPS (`live:last:*`, `live:geo:*` GEO set, per-minute dedup buckets). Not persisted in the compose setup (no volume).
