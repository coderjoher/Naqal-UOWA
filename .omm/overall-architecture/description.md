Naql Jamiat Warith is the campus transport system of Warith Al-Anbiyaa University. It is a pnpm + Dart pub monorepo with one NestJS API (apps/api), one React office dashboard (apps/dashboard), two Flutter apps (apps/student_app for riders, apps/driver_app for bus and taxi drivers), shared Flutter packages (packages/naql_ui, naql_core, naql_app) and a design-token generator (packages/design-tokens). The API owns all business logic: student identity, driver onboarding, waves and dispatch of bus runs, on-demand taxi rides, subscriptions/payments, driver settlement, live GPS tracking and notifications. State lives in PostgreSQL (via Prisma) and Redis (queues, caches, rate limits, live positions, Socket.IO pub/sub). Everything runs as Docker containers defined in docker-compose.yml, with a public-server overlay in deploy/oracle.
