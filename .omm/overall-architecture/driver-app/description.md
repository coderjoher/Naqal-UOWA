Flutter app for drivers (apps/driver_app). Drivers sign in with phone + SMS OTP, submit an application with documents, see today's runs and schedule, drive a run (start/arrive/board/depart/end actions plus a GPS fix every 5 s), collect pay-per-ride cash fares, go online for on-demand taxi offers and track earnings/settlements. Actions and GPS are queued in naql_core's offline outbox (SyncQueue) and pushed every 5 s so a run keeps working without network (NF-09). Built for Android and web (port 8082).
