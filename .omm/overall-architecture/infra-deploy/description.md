Container and operations setup. docker-compose.yml defines the local stack (postgres, redis, osrm download/prepare/serve, api on :3000 + metrics :9464, dashboard :8080, student-web :8081, driver-web :8082) plus opt-in profiles: backup, observability (Prometheus, Grafana, Jaeger) and https (Caddy with Let's Encrypt). deploy/oracle overlays it for a public VM: only Caddy 80/443 is exposed, secrets come from .env, services restart unless-stopped.
