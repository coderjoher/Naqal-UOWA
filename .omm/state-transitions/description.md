The persisted state machines of the Naqal API (apps/api). Each child element is one Prisma enum-backed lifecycle: RideStatus (bus ride requests), RunStatus (one bus doing one wave on one date), TaxiRideStatus (P10 campus taxis), DriverStatus (driver application review) and SubscriptionStatus (monthly subscription). The top-level graph shows how the machines feed each other: an approved driver becomes eligible for wave planning or taxi offers, an active subscription sets the subscriber flag and fare of a ride request, assigned requests become run stops, and run actions (depart, end) close requests as no_show or done.
