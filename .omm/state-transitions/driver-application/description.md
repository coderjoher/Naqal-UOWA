DriverProfile.status (enum DriverStatus): driver application and vehicle review (DR-01, TO-02). The office transitions are a pure table in drivers/driver-rules.ts (TRANSITIONS / nextStatus: approve pending->approved, reject pending->rejected, suspend approved->suspended, reinstate suspended->approved); DriversService.review (drivers/drivers.service.ts) applies them and stamps reviewedAt/reviewedById/reviewNote. The driver side is DriversService.submit: allowed only while editable (draft or rejected) and only when missingRequirements() against the university's TO-01 requirements is empty.
