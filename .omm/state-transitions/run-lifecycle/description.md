Run.status (enum RunStatus): one bus doing one wave on one date (DS-02, DR-04). Runs are created as planned by DispatchEngine.save() when a wave is planned or an extra run is added; a planned run left with no riders is deleted (freeing the driver). Driver actions arrive via POST /runs/:id/actions and are applied by RunsService.applyOne (runs/runs.service.ts) using the pure nextRunState / stopDeparture rules (runs/run-rules.ts): planned -> started -> at_stop -> started -> ... -> done. Each applied action writes a RunEvent, emits LiveHub.runStatus ('run' event), invalidates officeViews and the LiveService route cache, and 'end' triggers SettlementService.verifyRun (GPS proof, SE-02).
